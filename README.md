# 손목 위의 시계

Android Chrome에서 손목을 비추고 3D 시계를 착용해 보는 웹 프로토타입입니다.

**실행 주소:** https://bluewhale127.github.io/wrist-try-on/

## 휴대폰에서 사용하기

1. Android Chrome에서 위 주소를 엽니다.
2. **카메라 시작**을 누르고 카메라 권한을 허용합니다.
3. 밝은 곳에서 손등이 카메라를 향하도록 하고 손가락과 손목을 함께 보여 주세요.
4. 시계 크기, 착용 위치, 방향을 맞춥니다.
5. 준비한 시계가 있으면 **내 시계 불러오기**에서 `.glb`를 선택합니다.

카메라 영상과 선택한 시계 파일은 기기 안에서 처리하며 서버로 업로드하지 않습니다. 첫 페이지 접속 때 추적 모델 등 실행 파일을 다운로드합니다. 카메라를 끄거나 다른 탭/앱으로 이동하면 스트림을 종료합니다. 모델과 조절 값은 새로고침하면 초기화됩니다.

## 기능

- 후면 카메라를 기본으로 사용하는 손목 위치·방향 추적
- 직접 만든 임시 시계와 GLB 모델 교체
- 크기, 손목 위 위치, 시계 회전, 모델 기울기·높이 조정
- 손목 뒤 스트랩을 가리는 근사 처리
- 카메라 권한 오류 안내와 추적 손실 시 시계 숨김

## 0.2 추적 개선

- 손가락 끝 대신 손목과 네 손가락의 시작 관절을 함께 사용합니다.
- 화면상의 손 방향과 3D 기울기를 분리하고, 옆으로 기울었을 때 각도가 갑자기 뒤집히지 않도록 기울기를 제한합니다. 불확실한 기울기는 마지막 안정된 값을 유지합니다.
- 움직이는 속도에 따라 위치 보정 강도를 조절하고 크기 변화와 순간적인 위치 튐을 완화합니다.
- 짧은 누락은 최대 220ms 유지하고, 그 뒤에도 손을 찾지 못하면 시계를 숨깁니다.
- 가능한 브라우저에서는 Web Worker에서 추적합니다. 처리 중인 프레임을 쌓지 않으며 입력의 긴 변은 최대 640픽셀로 줄입니다. Worker를 사용할 수 없으면 기존 스레드에서 동작합니다.
- 기기 성능에 따라 최대 30회/초를 목표로 추적합니다. 실제 속도는 화면에 표시되며 기기마다 다릅니다.

## 모델 준비

- glTF 2.0 `.glb`로 내보내며 텍스처와 데이터를 파일 안에 포함합니다.
- 초기 권장 목표는 5~10MB 이하, 텍스처 1K~2K입니다. 파일 선택 상한은 40MB입니다.
- 본체·유리·스트랩을 분리해 두면 후속 조정에 편리합니다.
- 케이스 지름·두께·스트랩 폭을 mm로 함께 준비합니다. 현재 크기 조절은 실제 치수 측정 기능이 아닙니다.
- 좌표 기준: X는 케이스 좌우, Y는 다이얼 12시·6시와 스트랩 방향, +Z는 다이얼 앞면입니다. 피부 접촉면을 Z=0으로 두면 맞추기 쉽습니다.
- X축 전체 너비를 기준으로 정규화하고 X/Y 중심은 가운데 맞추며 Z 원점은 유지합니다.
- 스트랩은 손목을 감싸는 착용 형태로 모델링합니다. 펼쳐진 스트랩을 자동으로 구부리지는 않습니다.
- 기본 시계 회전은 90°입니다. 모델에 따라 방향·높이 설정을 조절합니다.
- Draco 압축은 지원합니다. KTX2/BasisU와 Meshopt 압축은 끄고 내보내 주세요.

## 로컬 개발

Node.js 20 이상이 필요합니다.

```sh
npm ci
npm start
```

PC에서 http://localhost:4173 을 엽니다. `npm start`가 버전이 고정된 라이브러리와 공식 추적 모델을 `vendor/`에 준비합니다. 모델 파일은 SHA-256 해시를 검사합니다.

```sh
npm test
npm run build
```

`dist/`가 HTTPS 호스팅용 결과물입니다. GitHub Actions가 main 브랜치에 변경 사항이 반영될 때 테스트·빌드 후 GitHub Pages로 배포합니다. Pages 설정의 배포 Source는 **GitHub Actions**입니다.

휴대폰에서 로컬 개발 서버를 보려면 USB 포트 전달을 사용합니다. ADB가 설치된 PC에서는 `adb reverse tcp:4173 tcp:4173` 실행 후 휴대폰 Chrome에서 http://localhost:4173 을 엽니다. 같은 Wi-Fi의 일반 HTTP IP 주소는 카메라 보안 조건을 만족하지 않습니다.

## 현재 한계와 검증

단일 RGB 카메라의 손 관절을 사용한 시각적 추정입니다. 손목 둘레나 실제 시계 크기를 측정하지 않습니다. 손등이 보이는 자세에 맞춘 초기 버전이며 손바닥/손등을 자동 분류하지 않습니다. 큰 회전, 빠른 움직임, 손가락 가림에서 어긋날 수 있습니다.

가림 처리는 보이지 않는 타원형 손목 모형을 사용합니다. 정밀한 피부 분할, 소매나 다른 물체에 의한 가림, 접촉 그림자, 환경 반사, 스트랩 자동 변형은 구현하지 않았습니다. 팔 자체의 방향은 추적하지 않으므로 손목을 크게 꺾으면 손 방향과 팔 방향이 달라져 어긋날 수 있습니다.

단위 검사와 데스크톱 Chromium에서 모바일 화면, GLB 교체, 권한 거부 후 복구, 실제 MediaPipe 모델에 테스트 손 영상을 입력하는 추적, 손이 사라질 때 숨김, 카메라 스트림 종료를 확인했습니다. 실제 Android 기기에서의 추적 정확도와 속도는 별도 검증이 필요합니다.

0.2에서는 깊이 이상값, 옆면 자세, 누락·재검출, 위치 튐, 정지 흔들림과 이동 지연의 회귀 검사를 추가했습니다. 화면 녹화를 로컬에서 재분석해 이전 자세 계산과 비교했습니다. 화면 녹화에는 기존 AR 오버레이가 포함되어 있으므로 원본 카메라 영상이나 실제 위치 정답에 대한 정확도 평가와는 다릅니다. 검증용 개인 영상은 저장소와 배포에 포함하지 않습니다.

## 구현과 출처

[VeinSyct/Wrist-AR](https://github.com/VeinSyct/Wrist-AR)의 카메라 → 손 추적 → 시계 정렬 흐름을 참고한 **독립 구현**입니다. 원본 저장소를 수정한 포크는 아닙니다.

원본 검토 커밋은 `b21e71ae69edeafab22da277b27f4b8282254bb2`입니다. 원본의 public 코드는 MediaPipe를 사용하지만, dist의 SDK 메타데이터는 DeepAR 5.6.19를 선언합니다. 이 프로젝트는 해당 SDK·키·인코딩된 코드·브랜드 시계 모델을 포함하지 않습니다.

- Three.js 0.180.0 (MIT)
- MediaPipe Tasks Vision 0.10.32 (Apache-2.0)
- 공식 Hand Landmarker float16 모델, 버전 1
- 직접 작성한 임시 시계 모델

관련 고지는 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)를 확인하세요.

## 주요 파일

- `app.js`: 카메라, 렌더링, GLB 불러오기, UI
- `pose.js`: 화면 좌표와 손목 위치·방향 추정
- `hand-detector.js`, `hand-worker.js`: 비동기 손 추적과 호환 모드
- `watch.js`: 임시 시계, 가림 모형, GLB 검사
- `index.html`, `style.css`: 모바일 화면
- `prepare-assets.mjs`, `build.mjs`: 실행 파일 준비·빌드
- `core.test.mjs`: 좌표 변환과 GLB 검사
